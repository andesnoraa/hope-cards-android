# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

# Android releases

- Build production Android App Bundles locally with Expo Prebuild and Gradle/Android Studio.
- Use the existing Hope Cards upload keystore and increment `expo.android.versionCode` for every release.
- Do not use EAS Build or EAS Submit unless the user explicitly requests EAS.
- Publish locally built `.aab` files through Google Play Console or the Google Play Developer API.
