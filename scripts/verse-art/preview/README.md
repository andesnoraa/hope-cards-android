# Verse image design previews

This opt-in native Android authoring tool produces review assets. The approved artistic rendering is also integrated into the app by `VerseArtRenderer` and `VerseArtImages`; the gallery now follows the selected Bible edition and exports JPEGs. No new dependency or background service is required.

## Design

- The original six quiet directions: misty forest, muted wheat, blush flowers, moonlit lake, misty mountains, and a dew-covered leaf. Detail stays at the edges; the verse has clear space.
- Artistic Latin-script collection: Upright Caveat Brush and Bebas Neue for highlighted phrases; Bebas Neue or DM Sans for small spaced uppercase supporting lines. The original Lora/DM Sans/Oswald/Caveat comparison assets are superseded by this artistic pass.
- Malayalam: Manjari Regular, Baloo Chettan 2 Medium, Noto Sans Malayalam Regular. Android shapes the original Unicode text; no letter spacing or synthesized italic is applied.
- Exact complete edition text is copied from the repository and compared with the corresponding source export. Text is never generated by AI. Any emphasis must be an exact substring, preserving punctuation and word order. Latin uppercase and deliberate line breaks are presentation only; the original source text remains intact in the manifest and review page. No letter spacing is applied to Malayalam.
- Every card includes the localized citation, edition label, and a subtle text-only Hope Cards watermark at the bottom right (22px at 1080px, 60% opacity, 54px right/baseline inset). Notification edition-label preferences do not affect these shareable verse images.

## Original user photographs (September 22)

Twenty original photographs are imported by `import_photos.py` from the supplied Downloads files. They are cropped to a square, resized to 1080px, and encoded as WebP at quality 88; their colors, sharpness, scenery, and subjects are not regenerated, blurred, or tinted. `photo-sources.json` records the original filename, SHA-256, crop rectangle, and encoding settings. The twenty photo backgrounds total 3.27 MiB. Keep original JPEGs unchanged.

`photo-profiles.json` specifies quiet text regions, preferred ink colors and subject-aware text placement. The deer uses a left-side text block. Large sky regions use dark lettering. Photo backgrounds receive no full-image overlay. The watermark remains text-only at the bottom right. All languages can use photographs with enough text space; Malayalam and longer eligible text select roomier layouts. Twenty source-verified English photo designs are included in the 44-card authoring review set. There are no washout, tint, brightness, or other photo filters; readability comes from text placement and adaptive lettering. A 64 × 64 luminance grid samples the original photo beneath each text block and citation. Dark or ivory ink is chosen for the local region; mixed-contrast areas get a thin contrasting edge on the glyphs only. The bitmap itself is never washed out or tinted. The 32 KB luminance grid is temporary and needs no extra image cache.

## Shorter complete verses and brighter artwork

The gallery applies `VerseArtEligibility` separately for each Bible edition: up to 130 characters / 22 words for Latin scripts, and 140 Unicode code units / 16 words for Malayalam. Long entries remain in the source Bible catalog and existing verse favorites; they are omitted from the sharing gallery without trimming, paraphrasing, or adding ellipses. Counts and category cover fallbacks follow the selected edition. The regenerated set has 1,175 cards and 635 omitted edition-specific entries, recorded in `output/verse-art-regenerated/`.

The renderer uses upright Caveat Brush and Bebas Neue faces, with no slanted script or italic styles. It measures complete words before fitting so words such as SHEPHERD cannot be split mid-word. Malayalam retains its script-specific font set and native shaping. All templates are invalidated by the `artistic-v11-adaptive-lettering` cache version.

Sunlit flowers and the green meadow were explicitly approved and are in the app. Sunlit ferns and fresh leaves were subsequently approved and are also in production assets. Fresh leaves retains Caveat Brush with Bebas Neue, the typography the user preferred. Woodland clearing remains test-only and is not included in production. Their text placement differs to keep foliage clear of Scripture. The brighter approved templates place the citation above the scenery and keep the subtle watermark at bottom right.

## Reproduce

Fonts, licences, download hashes, static font instances, design specifications, and backgrounds are in `android/app/src/androidTest/assets/verse-art-preview/`. Variable fonts were instantiated at fixed axes using fontTools so the eventual design is not dependent on variable-font support. Noto Sans Malayalam uses the app's existing font and licence.

1. Optional font refresh: run `download_fonts.py` in a Python environment with fontTools. Review updated hashes before accepting a refreshed source.
2. Run `python3 scripts/verse-art/preview/prepare_designs.py /path/to/edition-source-cache` to compare Scripture with the source exports. Existing source-cache format is documented by `scripts/daily-verses/sources.py`.
3. Build the debug app and androidTest APK with local Gradle, then install them on an emulator.
4. Run `adb -s emulator-5554 shell am instrument -w -e class com.aaronsedna.hopecards.ui.GenerateVerseArtDesignPreviews -e generateDesignPreviews true com.aaronsedna.hopecards.debug.test/androidx.test.runner.AndroidJUnitRunner`.
5. Pull `/sdcard/Android/data/com.aaronsedna.hopecards.debug/files/verse-art-design-preview/` to `output/verse-art-design-preview/`.
6. Run `python3 scripts/verse-art/preview/build_review.py`.

The test asserts unchanged source text, no omitted text when applying emphasis, sufficient layout space, and fitting citation height. It renders sequentially and releases bitmaps after each card. Test-only authoring assets never enter the release APK.

## Production integration

The native gallery uses twenty-nine shared WebP backgrounds and a fixed font set. A single cancellable render queue generates only requested thumbnails/details. The bitmap cache is capped at 8 MiB; rendered-image and shared-export disk directories are capped at 32 MiB each. Application memory callbacks clear the bitmap cache. The renderer retains application context only, and creates no periodic job, wake lock, or service. Gallery captions show only the localized citation and favorite control; the Bible text, citation and edition label follow the selected translation. Reviewed design overrides are used only when their source text still matches exactly. Other entries use the verified verse text, existing matching English emphasis where available, and deterministic phrase/type/background selection.

The original baked artwork files live only in `android/app/src/androidTest/assets/verse-art/` for the legacy authoring workflow. They are excluded from both debug and release app packages; the gallery, saving, and sharing use the native renderer.

### Rendering principles

Keep a small reusable WebP background library, compact static fonts, and verified edition text. Render locally with Android Canvas/StaticLayout at the requested size: approximately 360px thumbnails and 1080px detail/share images. Generate only requested cards on a bounded background dispatcher; do not create all translations, fonts, and backgrounds at startup. Cancel work for offscreen items.

Use a byte-bounded bitmap memory cache and a bounded disk cache. Include verse ID, edition ID, source-text hash, background version, template/font version, and output size in the cache key. Stable design selection avoids appearance changing during scrolling. Decode backgrounds near the destination size. A 1080px ARGB bitmap alone occupies about 4.45 MiB; a 360px bitmap about 0.49 MiB, irrespective of compressed file size.

Keep small WebP assets internally. Export JPEG on demand for sharing and reuse an existing export when its cache key matches. Use real native text rendering, not AI text generation, to preserve Scripture and Malayalam shaping. No periodic rendering, service, wake lock, or background pre-generation is needed.

The authoring tool deliberately creates both JPEG and WebP versions to compare appearance and size; production would not eagerly store every combination. Emulator render timings are illustrative authoring measurements, not a battery benchmark or a guarantee of low-end phone performance.

To regenerate the full eligible collection, run `VerseArtRenderingInstrumentedTest` with `-e regenerateGallery true`, pull `verse-art-regenerated` from the debug app's external files, and run `build_collection_review.py`. The review script compares every complete verse with its matching cached edition source, using the already-reviewed Luther superscription and Italian/Spanish annotation rules. The complete generated collection is a review artifact; it is not bundled into the app or generated at startup.

To reproduce the original three-option greenery comparison, run `GenerateVerseArtDesignPreviews` with `-e generateDesignPreviews true -e greeneryPreview true` and pull `verse-art-greenery-preview`.

### Stable visual shuffle

`VerseArtOrder` separates scene families and recent repeated backgrounds using the actual selected-edition design. It is deterministic across reopening and recomposition, applies to categories and Saved, and preserves artwork/favorite IDs. Photos remain on disk once; no extra bitmap cache is allocated for ordering. Closely related alpine lakes, forest scenes, golden fields and botanical textures share families. A small or visually homogeneous Saved selection can still repeat a family when no alternative remains.
